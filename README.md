// Indonesian
🌱🤖 SMAHIR adalah inovasi pertanian hidroponik pintar yang kami kembangkan dengan teknologi robotika. Sistem ini mampu merawat tanaman secara otomatis, mengurangi penggunaan lahan, serta meminimalkan tenaga kerja.
Melalui proses pemindaian tanaman, sistem dapat menganalisis kondisi tanaman lalu secara otomatis memanen atau membuang tanaman yang tidak sesuai. 🌿✨
SMAHIR menunjukkan bagaimana inovasi dan teknologi dapat menjadi solusi untuk masa depan pertanian yang lebih efisien dan berkelanjutan.

// English
🌱🤖 SMAHIR is a smart hydroponic farming innovation we developed using robotics technology. This system can automatically care for plants, reduce land use, and minimize labor.
Through plant scanning, the system can analyze plant conditions and then automatically harvest or remove unsuitable plants. 🌿✨
SMAHIR demonstrates how innovation and technology can be solutions for a more efficient and sustainable agricultural future.
